# Mode: offers — Multi-Offer Comparison

When the candidate provides multiple offers (or multiple evaluations already done), compare them side by side to help in decision making.

## Analysis Process

1. **Read evaluation reports** from `reports/` for each company mentioned.
2. **Read `_profile.md`** to confirm candidate's current priorities (e.g., "remote first", "comp focus", "learning focus").
3. **Analyze trade-offs** between the offers.

## Ranking and Recommendation

1. **Ranking**: 1st, 2nd, 3rd with brief justification.
2. **Candidate-Archetype Fit**: Which one aligns best with the candidate's long-term exit narrative.
3. **Negotiation Leverage**: How to use Offer B to improve Offer A (if applicable).
4. **Final Verdict**: Recommendation on where to invest most effort or which one to accept.
